# onepage-tutorial

一个把「真实实践经验」写成**一页纸教程**的技能（skill）。

给 DSH / Claude Code 这类能加载技能的 agent 用。触发词：`写个一页纸`、`把这件事做成一页纸教程`、`生成一页纸`、`整理成能分享给同学的教程`。

## 它解决什么问题

写一页纸教程最容易出的三个毛病，这个技能各有一道闸：

| 毛病 | 闸门 |
|---|---|
| 编数据、编链接、编案例 | **不编造**——每个数字都要能指向来源，查不到就删或标 `【待核实】` |
| 套模板写成填空题 | **不套模板**——有几节写几节，官方模板只是底线不是标杆 |
| 只写结论，读者学不到判断 | 坑必须写「**怎么发现的**」，不能只写「有这个坑」 |

## 五条铁律

1. **不编造** —— 数字、版本号、命令、报错、链接、截图必须来自真实素材；查不到就删，不写"大约""据说"
2. **先 MD 后发布** —— 本地 Markdown 没被用户确认，不得推送到任何平台
3. **每轮一个文件带版本号** —— 改稿新建 `-v2`、`-v3`，不覆盖上一版；发布侧标题不带版本号
4. **不套模板** —— 章节可增可删，把事讲清楚优先
5. **正文不复述标题** —— 第一个 `#` 必须是章节名，不能等于文章标题

## 安装

DSH 有两处技能目录，二选一或都放：

```
# 全局（所有工作区可用）
~/.dsh/skills/onepage-tutorial/SKILL.md

# 项目级（只在该工作区可用）
<项目根>/.dsh/skills/onepage-tutorial/SKILL.md
```

```bash
git clone https://github.com/hadestemplar/onepage-tutorial.git
cp -r onepage-tutorial ~/.dsh/skills/onepage-tutorial     # Linux / macOS
# Windows: xcopy onepage-tutorial %USERPROFILE%\.dsh\skills\onepage-tutorial /E /I
```

技能是纯 Markdown，无依赖、无构建、不执行代码。

## 用法

对着 agent 说一句就行：

```
把这件事做成一页纸教程：我上周用 XXX 解决了 YYY 问题
```

技能会走四段：

1. **采料** —— 从真实实践里挖六类东西：场景与痛点、工具栈、关键步骤（含提示词原文）、真实结果数字、踩坑与发现过程、可复现的前提条件
2. **成稿** —— 按内容自定章节，每步给命令/路径/验证方法
3. **自检** —— 可复现性、篇幅、编造痕迹
4. **发布** —— 本地 MD → 用户确认 → 推送平台

**采料环节是骨架不是形式**：没有真实数字和真坑，成稿必然是假文章。

## 可选：飞书发布脚本

技能内置了一段飞书发布流程，需要配套的四个脚本（不在本仓库，属于作者私有工具链）：

| 脚本 | 作用 |
|---|---|
| `lark-md-push.mjs` | Markdown → 飞书 docx（表格 / 代码块 / 图片 / 高亮块） |
| `lark-del.mjs` | 删除文档 |
| `lark-list.mjs` | 列目录 |
| `lark-perm.mjs` | 设公开权限 |

**没有这套脚本也能用**——技能会输出到本地 Markdown，你手动贴到飞书即可。

## 目录结构

```
onepage-tutorial/
└── SKILL.md        # 全部内容（144 行）
```

技能刻意做成单文件：一页纸教程这件事本身不复杂，拆成 references/ scripts/ 反而增加加载成本。

## 已知限制

- **飞书 heading 无法自动编号**：`heading1/2/3` 的 `style` 只有对齐与折叠，章节序号只能手写。
- **跨租户文档抓不干净**：别人租户里的飞书文档走云端抓取会丢标题层级和图片，只适合看个大概。
- **模板只管 60 分**：官方模板自己就写明「这是一个方便达到 60 分的模板」，想要更好得靠自己的素材。

## 出处

技能从一次真实交付里提炼：作者用 Agent 把得到课程批量导出成本地 Markdown，写成教程后回溯「哪些环节本来可以少走弯路」，把规则固化下来。

坑表里的每一条都是实际踩过的，包括：

- 飞书表格 cell 与高亮块**都自带一个空文本块**，直接 addKids 会多出空行（同一个坑踩了两次）
- 有序列表的 `style.sequence` **必须省略**——硬编码 `"1"` 会渲染成 `1.1.1.1`，传空串 `""` 会让整批请求失败
- 一篇两万字的稿子被否掉，根因是第一版照着官方模板逐段填空
